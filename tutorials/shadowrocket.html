2026 小火箭 Shadowrocket 节点订阅与规则分流实战

📅 更新时间：2026-11-02 ✍️ 作者：环球梯移动网络工程部 ⏱️ 阅读时长：约 5 分钟 🏷️ 标签：Shadowrocket, iOS 小火箭, 规则分流

在 iPhone 与 iPad 设备上，Shadowrocket（俗称“小火箭”）凭借极其轻量的内存开销、秒级冷启动速度以及对各种新型混淆协议的敏锐适配，长期稳居 iOS 加速生态首选地位。配合环球梯的高质量企业级 IEPL 专线，能够让移动端用户在日常出行、海外流媒体追剧以及移动 AI 对话中实现真正的“无感加速”。

本实战教程将指导您完成 Shadowrocket 的正确导入姿势、分流策略设置与省电抗断流优化。

准备工作：客户端获取

由于 App Store 政策，Shadowrocket 仅在非中国大陆区（如美区、日区、港区等）App Store 上架。请使用您的海外 Apple ID 登录 App Store 搜索下载，认准开发者为 Shadow Launch Technology Limited，图标为浅蓝底色白色飞天火箭，谨防冒牌山寨应用。

步骤一：将环球梯订阅添加至小火箭

环球梯支持两种快速添加方式，操作极其便捷：

  1. 方式一：一键自动导入（推荐）
    使用 Safari 浏览器登录 环球梯用户中心，在“便捷导入”区域点击“一键导入 Shadowrocket”。系统将自动跳转并拉起小火箭应用，直接弹出“保存”确认弹窗。
  2. 方式二：扫描二维码或手动链接导入
    若在电脑端打开网页，可以在手机上打开小火箭，点击右上角的 扫描图标 (扫一扫)，直接扫描电脑屏幕上的订阅二维码；或在手机端复制订阅链接，点击小火箭右上角 + 号，类型选择 Subscribe，在 URL 栏粘贴链接，备注填写 环球梯 并点击右上角“完成”。

添加成功后，小火箭会自动下载并展开 60+ 优质专线节点列表，包括香港、台湾、新加坡、日本与美国等专线服务器。

步骤二：全局路由设置（至关重要）

在小火箭首页下方，有一项名为 全局路由 (Global Routing) 的核心选项，默认可能处于不同状态，请按照以下准则核对：

  • 配置 (Config，务必选择此项)： 相当于桌面端的“规则模式”。根据内置规则智能分流，访问微信、支付宝、网易云等国内服务完全直连不消耗流量；访问海外应用自动经由环球梯高速节点加速，体验与安全兼顾。
  • 代理 (Proxy)： 全局代理模式。所有软件流量均走境外节点，容易造成国内软件定位异常或加载变慢，非特殊需求切勿开启。
  • 直连 (Direct)： 停用代理，全部走本地蜂窝网络。
  • 场景 (Scene)： 支持根据 Wi-Fi 名称自动切换不同策略，适合高级用户。

步骤三：首次连接与 VPN 授权

  1. 在节点列表中，选中任意低延迟节点（例如 香港01-企业专线优选 或 新加坡01-狮城跃迁）。节点右侧出现黄色或橙色对勾即为当前生效节点。
  2. 将小火箭顶部主开关拨向 “未连接 → 已连接”。
  3. 若是首次启动，iOS 系统会弹出“Shadowrocket 想添加 VPN 配置”的系统对话框，点击 允许 (Allow)，并输入手机锁屏密码完成授权。
  4. 状态栏出现 VPN 小图标，即代表连接成功，您可以打开 YouTube、X (Twitter) 或 ChatGPT APP 测试极速响应体验。

步骤四：开启自动更新与切网保持稳定

为了保证您的节点始终保持最新物理通道，建议开启以下进阶特性：

💡 开启订阅自动更新：
点击小火箭底部 设置 (Settings) → 订阅 (Subscribe)，打开 “打开时更新” 与 “后台自动更新” 开关。这样每次启动应用，小火箭均会自动向环球梯同步最新低延迟路由。

5G 与 Wi-Fi 无缝切网优化：
进入小火箭 设置 → TCP，将 连接复用 (Multiplex) 与 快速打开 (TCP Fast Open) 保持开启。结合环球梯后端的 BBRv3 链路，当您从公司或家庭 Wi-Fi 走入电梯切换至 5G 基站时，正在进行的音频通话与视频流媒体可在 0 秒内平滑过渡，告别断流重试。

iOS 端常见疑难自查

  • Q：小火箭连上后，所有网页都打不开？
    请检查手机系统时间是否精准；前往“设置 → 通用 → 日期与时间”开启“自动设置”。
  • Q：ChatGPT iOS 客户端登录提示国家不受支持？
    请在小火箭节点中选择 美国01~10-自由星链 或 新加坡01~10-狮城跃迁。环球梯提供经过风控测试的干净原生住宅家庭宽带 IP，可直接秒解 OpenAI 客户端登录与额度查询。
